# Task for DevOps vacancy
В данном задании был написал скрипт, который мониторит процесс test в ОС Linux, в данном случае Ubuntu. Скрипт отвечает требованиям:
1. Запускается при запуске системы и отрабатывает каждую минуту;
2. Если процесс запущен, то стучится по заданному адресу;
3. Если процесс был перезапущен, то делает соответствующую запись в логе;
4. Если заданный адрес сервера на доступен, то делает соответствующую запись в логе.
